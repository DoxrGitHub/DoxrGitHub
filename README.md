Here are a couple of things to check out if you're interested:

> [DOPE](https://github.com/DoxrGitHub/DOPE)

An RSA/assymetric encryption re-implementation from scratch for fun called DOPE (Doxr Open Protocol Encryption), one of my only cryptographic projects. 

> [Doxr's Blog](https://github.com/DoxrGitHub/doxrblogs)

A blog website that I have made. Contains public disclosures for vulnerabilities I have found.

> [Gus Payment Processor](https://github.com/DoxrGitHub/gus)

A self-hosted payment system for Chrome extensions. Gus gives you full control over monetization, with no fees (you keep 100% of the revenue) and fine-control integration.

> [GhostBox](https://github.com/DoxrGitHub/ghostbox)

A no-bloat temporary email client made to make using temporary emails super easy and convenient.

> [Secordis](https://github.com/secordis/secordis)

A project to create a new, open source blocking system; one made for low end school Chromebooks.

> [clientDB](https://github.com/DoxrGitHub/clientDB)/[nodeDB](https://github.com/DoxrGitHub/nodeDB)

JSON "database" library; makes it really easy to work with persistent JSON files (or `localStorage` for the client version) for simple KV database usage. Inspired by Replit's KV built in database.
